# MSBA325 Tourism Dashboard

This project is an interactive Streamlit dashboard exploring tourism facilities across Lebanese towns.

## Dashboard Features

- Filter towns using a Tourism Index range.
- Explore tourism facilities across towns using interactive visualizations.
- Select a specific town for a detailed breakdown of its tourism facilities.
- Use linked interactions to move from a broad Tourism Index selection to a specific town.

## Dataset

The dashboard uses the MSBA325 tourism dataset containing information about hotels, cafes, guest houses, restaurants, and the Tourism Index across Lebanese towns.
